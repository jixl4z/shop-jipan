## 💳 ระบบตรวจสอบสลิปอัตโนมัติ (Slip Verification)

ระบบรองรับทั้ง **โหมดทดสอบ (Simulation)** และ **API จริงในไทย**:
1. **โหมดทดสอบ (Simulation Mode - ตั้งค่าเริ่มต้นไว้แล้ว):**
   - ลูกค้าเลือกยอดเงิน -> สแกน QR PromptPay -> แนบรูปสลิป -> กดยืนยัน ระบบจะจำลองการตรวจสอบและเติมเงินเข้ากระเป๋าตังค์ทันที เหมาะสำหรับทดสอบ Flow
2. **โหมดเชื่อมต่อ API จริง (เมื่อพร้อมเปิดร้าน):**
   - เข้าหลังบ้านที่ **`/admin/settings`**
   - ใส่หมายเลขพร้อมเพย์ของคุณ (เบอร์โทร หรือ เลขบัตร ปชช./นิติบุคคล)
   - เลือกผู้ให้บริการตรวจสลิป:
     - **SlipOK** (แนะนำสำหรับไทย: ใส่ API Key และ Branch ID)
     - **EasySlip**
     - **OpenSlipCheck**
   - เมื่อลูกค้าโอนเงินและส่งสลิป ระบบจะยิงตรวจกับธนาคารจริง พร้อมเช็ค `transRef` ป้องกันการส่งสลิปซ้ำ 100%

## ☁️ การเชื่อมต่อกับ Supabase (ฟรี)

ปัจจุบันโปรเจกต์รันด้วยฐานข้อมูล SQLite ในเครื่อง (`dev.db`) เพื่อให้เปิดทดสอบได้ทันที เมื่อคุณต้องการเชื่อมต่อกับ Supabase ฟรี:

1. เข้าไปที่แดชบอร์ด **[Supabase](https://supabase.com)** -> ไปที่ **Project Settings** -> **Database**
2. คัดลอก **Connection String (Transaction Pooler - Port 6543)**
3. เปิดไฟล์ `prisma/schema.prisma` แล้วเปลี่ยน:
   ```prisma
   datasource db {
     provider = "postgresql"
     url      = env("DATABASE_URL")
   }
   ```
4. ในไฟล์ `.env` ให้วาง URL จาก Supabase:
   ```env
   DATABASE_URL="postgresql://postgres.[YOUR-PROJECT-REF]:[YOUR-PASSWORD]@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres?pgbouncer=true"
   ```
5. รันคำสั่งซิงก์ฐานข้อมูลและสร้างข้อมูลเริ่มต้น:
   ```bash
   npx prisma generate
   npx prisma db push
   node prisma/seed.js
   ```

## 🌐 การผูกโดเมน 50 บาท (Deploy บน Vercel ฟรี)

1. อัปโหลดโค้ดนี้ขึ้น **GitHub** (Private Repo ได้)
2. ไปที่ **[Vercel](https://vercel.com)** -> กด **Add New Project** -> เลือก Repo ของคุณ
3. ใส่ Environment Variables ใน Vercel:
   - `DATABASE_URL` = ลิงก์ Supabase PostgreSQL ของคุณ
   - `JWT_SECRET` = รหัสความลับความยาว 32 ตัวอักษรขึ้นไป
4. เมื่อ Deploy เสร็จ เข้าเมนู **Settings** -> **Domains** ใน Vercel
5. ใส่ชื่อโดเมน 50 บาทของคุณ แล้วไปตั้งค่า CNAME / DNS Records ตามที่ Vercel แนะนำ (ใช้เวลา 5-30 นาที โดเมนจะใช้งานได้ทันทีพร้อม SSL ฟรี)
